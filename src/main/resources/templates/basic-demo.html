How HTTP Basic Works

  1. User requests a protected resource.
  2. Browser displays a Username & Password popup.
  3. User enters credentials.
  4. Browser encodes credentials using Base64.
  5. Authorization header is sent with every request.
  6. Spring Security validates the credentials.
  7. User is authenticated.
